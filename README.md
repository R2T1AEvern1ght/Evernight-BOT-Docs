## 🎯 机器人简介

Evernight-BOT 是一款运行在 QQ 群内的多人文字游戏机器人。目前公开收录 **30 款游戏**，包含黑桃 7、红心 6、梅花 7、方块 10 款。
不同花色代表游戏的主要方向：

- **♠️ 黑桃**：反应、体力感、生存与风险。
- **♥️ 红心**：心理、推测、信任与博弈。
- **♣️ 梅花**：团队合作、公开交流与协作。
- **♦️ 方块**：逻辑、数学、推理与知识。

## 🚀 新玩家快速上手

1. 在已启用机器人的 QQ 群中发送 `/注册 昵称`（新昵称不超过15个支持的字符）。
2. 发送 `/目录` 浏览游戏，或发送对应 `/Game编号 规则` 查看官方详细规则。
3. 发送 `/Game编号 创建` 建房；其他玩家发送 `/加入 四位房号` 进入房间。
4. 由房主发送 `/开始`，根据游戏提示行动；可用 `/状态` 查看状态。
5. 完成比赛后使用 `/签证` 查看等级、EXP、金币、记录与收集情况。

> ⚠️ 部分游戏具有独立模式、指令或人数要求；请以 `/Game编号 规则` 和实际机器人提示为准。

## 👤 玩家账户与收藏

- **注册与昵称**：`/注册 昵称`、`/改名 新昵称`，按 QQ 用户身份保存。
- **签证档案**：`/签证` 可查询等级、经验、金币、胜负与卡牌收藏。
- **EXP 与金币**：达到游戏的有效时长并正常完成结算后，按照统一规则奖励；升级所需 EXP 随等级提高。
- **卡牌收藏**：依据不同游戏完成记录累积对应难度牌。
- **胜率显示**：`/胜率` 提供展示相关选项，包括隐藏与恢复。
- **头衔系统**：`/头衔商店` 浏览可购头衔；`/头衔` 查看、装备或卸下头衔。
- **周排行榜**：不同游戏有独立周榜；通常使用 `/Game编号 周榜`，部分游戏使用专属模式周榜。
- **游戏热度**：`/热度` 可查看游戏活跃度排名，按规则周期性衰减。

## 🏠 房间与多人管理

- 多人房间统一使用 **1000–9999** 的四位房号；房间结束后号码释放。
- 创建、加入、开始、退出与房间状态功能会按各游戏的规则执行。
- 游戏进行中的房主结束请求采用严格过半同意规则；两人房需双方同意。
- 提供房间踢人、投票踢人等群内管理能力；具体限制由游戏状态决定。
- 游戏内多数常用行动支持短指令；当同一群内存在歧义时须使用完整游戏指令。

## 🌐 语言系统

支持简体中文、英语、西班牙语、日语及繁体中文，可发送 `/语言 简体中文`、`/语言 English` 等切换。
个人语言设置会保存，不因机器人重启而消失。部分游戏提示与翻译可能存在版本差异。

## 🛠️ 其他功能

- **群聊激活**：管理员提供启用/停用与激活状态管理。
- **权限与封禁**：提供用户及群组的管理、限制功能。
- **交互聊天与 AI 辅助**：支持已集成的聊天/辅助能力；具体行为取决于服务配置。
- **Phigros ALL TAP（转全蓝）工具**：提供相关谱面转换功能；所需文件格式和指令以机器人说明为准。
- **版本查询**：`/版本号` 查看机器人版本与最近更新记录。
