# 🌑 Evernight-BOT — Official bot guide



**Version: v1.10.4** · **30 games**

Evernight-BOT is a QQ group bot featuring games, leaderboards and player progression.

## Quick start

1. `/注册 昵称`  2. `/目录`  3. `/GameXXIII 创建`  4. `/加入 1234`  5. `/开始`

## Features with examples

### Registration / profile

Register with a nickname, then view your profile.

**Example:** `/注册 测试玩家`

### Game list and rules

Look up a game’s full rules.

**Example:** `/GameXXIII 规则`

### Create a room

Create a multiplayer room; share the four-digit code.

**Example:** `/GameXXIII 创建`

### Join a room

Enter the actual room code announced by the bot.

**Example:** `/加入 1234`

### Start a match

The room owner starts the game after everyone joins.

**Example:** `/开始`

### Match status

Check the current state when the command is available.

**Example:** `/状态`

### Weekly leaderboard

View the weekly ranking for the selected game.

**Example:** `/GameXXIII 周榜`

### Player visa

View level, EXP, coins, and collection.

**Example:** `/签证`

### Titles

View available and equipped player titles.

**Example:** `/头衔`

### Language

Change your preferred bot language.

**Example:** `/语言 English`

### Game popularity

Check which games are currently popular.

**Example:** `/热度`

### Version

Check current bot version and recent changes.

**Example:** `/版本号`
