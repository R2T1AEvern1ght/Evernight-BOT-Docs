## 如何开始

1. 在 QQ 群中使用 `/目录` 找到游戏，先通过 `/Game编号 规则` 查看游戏内的完整说明。
2. 由房主使用对应创建指令建立房间，向其他玩家分享系统给出的四位房号。
3. 其他玩家发送 `/加入 房号`，房主发送 `/开始`，然后依照各游戏的提示行动。
