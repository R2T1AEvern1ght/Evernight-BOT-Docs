## Game I · ♠️4 ARENA（アリーナ） {#game-i}

**プレイ人数：** 2〜4人

### ゲーム概要

ターン制の対戦ゲームです。攻撃、防御でのシールド獲得、次の攻撃を強化するチャージを選びます。特殊モードではランダムなスキルが発生することもあります。

### 詳しい対局の流れ

1. 部屋主が通常／特殊モードを選び、2〜4人で参加します。全員が同じ初期ライフから開始します。
2. 自分の手番では攻撃・防御・チャージのいずれかを選びます。攻撃は蓄えたエネルギーを消費して威力を高め、防御はシールドを獲得し、チャージは次の攻撃を強化します。
3. 残り人数、ライフ、シールドの状態を見て即攻撃するか力をためるかを判断しましょう。特殊モードでは追加イベントの告知にも注意が必要です。

### 勝敗と得点

ほかのプレイヤーを脱落させ、最後まで生き残れば勝利です。

### 主なコマンド

- `/GameI 创建 普通`
- `/GameI 创建 特殊`
- `/攻击`
- `/防御`
- `/充能`
- `/GameI 周榜 普通`

**ボット内の完全な規則：** `/GameI 规则`

## Game II · ♠️2 NUMBER BOMB（数字爆弾） {#game-ii}

**プレイ人数：** ソロ／対戦2〜8人

### ゲーム概要

隠された爆弾の数字を順番に予想し、外れるたびに範囲が狭まります。対戦では当てたら脱落／勝利のルールを選択し、ソロには回数制限があります。

### 詳しい対局の流れ

1. ソロか対戦を選びます。対戦では、爆弾の数字を当てた人が脱落するモードか、当てた人が勝つモードかを部屋主が決めます。
2. ボットが示す範囲内で数字を予想します。外れると候補範囲が狭まり、次の人は更新された上下限から選びます。
3. 候補が減るほど判断が重要になります。脱落モードでは正解を避け、勝利モードでは範囲の変化を利用して隠し数字を先に見つけましょう。

### 勝敗と得点

設定したモードにより、正解するか最後まで生き残ると勝利です。

### 主なコマンド

- `/GameII 单人`
- `/GameII 创建 淘汰 3722`
- `/GameII 创建 获胜 3722`
- `/猜 100`

**ボット内の完全な規則：** `/GameII 规则`

## Game III · ♣️6 SITUATION PUZZLE（ウミガメのスープ） {#game-iii}

**プレイ人数：** ソロ／通常2〜16人／特殊個人戦2〜10人／2〜3チーム戦

### ゲーム概要

不可解な状況の真相を、質問への「はい・いいえ・関係なし」の回答から推理します。質問回数やチームの得点方式はモードによって変わります。

### 詳しい対局の流れ

1. まず不可解な状況文が提示されます。重要な背景は隠されており、選択したモードによりソロ推理・個人戦・チーム戦になります。
2. 人物の認識、行動の順番、原因などについて具体的に質問します。「はい／いいえ／関係なし」の返答を使い、矛盾する仮説を一つずつ消していきます。
3. 手がかりがつながったら、何が起きたのかを文章で「還元」提出します。単語だけでは十分でない場合があり、チーム戦では独自の質問・採点条件に従います。

### 勝敗と得点

隠された真相を正しく説明し、判定に通れば成功です。

### 主なコマンド

- `/GameIII 创建 普通单人`
- `/GameIII 创建 普通多人 5`
- `/出题`
- `/问 问题`
- `/还原 答案`

**ボット内の完全な規則：** `/GameIII 规则`

## Game VI · ♦️5 CIPHER（暗号解読） {#game-vi}

**プレイ人数：** ソロ／競走2〜8人

### ゲーム概要

6桁の暗号を推理します。Aは数字も位置も一致、Bは数字だけ一致することを示します。対戦では全員が同じ暗号に挑戦します。

### 詳しい対局の流れ

1. 6桁の秘密コードを推理します。ボットの入力形式に従い、ソロでは推理力、対戦では共通の暗号を解く速さを競います。
2. 各予想にはA/Bの結果が返ります。Aは数字も位置も正しく、Bは数字は含まれるが位置が違うことを示します。過去の結果を合わせて候補を絞り込みます。
3. 終盤でも以前のBの情報を忘れずに配置を考えましょう。競走では無駄な試行を減らし、できるだけ早く解読することが重要です。

### 勝敗と得点

先に暗号を解読した人が勝利。ランキングでは試行回数と時間も比較します。

### 主なコマンド

- `/GameVI 创建 单人`
- `/GameVI 创建 竞速`

### 勝敗と得点

## Game XVIII · ♣️A SYNC（シンクロ） {#game-xviii}

**プレイ人数：** 2〜8人

### ゲーム概要

全員がA/B/Cを選びます。最多人数の選択肢に合わせると得点、全員一致ならさらに高得点を得られます。

### 詳しい対局の流れ

1. 同じ回で全員がA/B/Cから一つ選びます。ほかの参加者がどれを選ぶかを読むゲームです。
2. 最も多い選択と一致すると同調点が得られ、全員の選択が完全一致すればさらに高いボーナスになります。
